# Faceless Content Creator n8n Dependencies

Baseline:
- Node.js >=22
- Next.js/React application in this repository
- Prisma + local SQLite or configured hosted database
- FFmpeg/eSpeak deterministic render path
- n8n

Optional production capabilities may require AI/video providers, storage, social publishing credentials and GPU presenter infrastructure. All external credentials must remain encrypted/outside Git and must flow through the application's existing workspace/plan authorization boundaries.
